# Nexus

注意力保护系统。按 `docs/DESIGN.md` 和 `docs/modules/*.md` 实现。

## 当前实现

- 六大主页面：仪表盘、事件流、任务、执行器、规则引擎、信息源
- 单用户本地模式：`localStorage` 持久化，刷新后保留状态
- 工作空间切换与新建，空间内事件 / 任务 / 规则 / 信息源隔离
- 事件流：按注意力级别、来源、关键词筛选，事件可直接转任务
- 任务页：看板 / 列表双视图，创建任务，状态流转，分配执行器
- 本地执行器闭环：任务可开始执行、进入运行中、写运行日志、成功/失败回写任务
- 真实执行器闭环：通过本地 Node API 调真实 CLI 执行器，返回摘要与日志
- 执行器统计：队列中 / 运行中 / 今日完成 / 失败次数 / 最近结果
- 仪表盘统计：真实 `Agent 处理中 / AI 已完成 / 执行失败`
- 规则页：启停规则、采纳建议、手动创建规则
- 信息源页：状态切换、启停模拟接线、真实 RSS 同步
- 对话面板：创建任务、切页、创建规则
- 命令面板与快捷键：`Cmd/Ctrl+K`、`Cmd/Ctrl+J`、`N`、`1-6`、`Esc`
- 右侧详情面板：任务详情、事件详情、状态动作、执行器分配、执行日志

## 启动

```bash
pnpm install
pnpm dev:api
pnpm dev
```

默认：

- Web: `http://127.0.0.1:5173`
- Local API: `http://127.0.0.1:4318`

## 当前边界

- 仅本地单用户模式
- 前端为 `Web SPA`，适配层为本地 Node API
- 已接首个真实信息源：RSS 轮询同步
- 已接首个真实外部执行器：CLI 执行器
- 规则仍是本地 store，未接真实规则插件
- 未接钉钉 / 邮件 / OpenCode / 远程服务端 / 云同步

## 快捷键

- `Cmd/Ctrl + K`：打开命令面板
- `Cmd/Ctrl + J`：开关对话面板
- `N`：快速创建任务
- `1-6`：切换主页面
- `Esc`：关闭命令面板 / 详情焦点 / 对话
