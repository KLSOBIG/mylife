# Nexus

注意力保护系统。按 `DESIGN.md` 和 `docs/modules/*.md` 实现首版 Web SPA。

## 当前实现

- 六大主页面：仪表盘、事件流、任务、执行器、规则引擎、信息源
- 单用户本地模式：`localStorage` 持久化，刷新后保留状态
- 工作空间切换与新建，空间内事件 / 任务 / 规则 / 信息源隔离
- 事件流：按注意力级别、来源、关键词筛选，事件可直接转任务
- 任务页：看板 / 列表双视图，创建任务，状态流转，分配执行器
- 规则页：启停规则、采纳建议、手动创建规则
- 信息源页：状态切换、启停模拟接线
- 对话面板：创建任务、切页、创建规则
- 命令面板与快捷键：`Cmd/Ctrl+K`、`Cmd/Ctrl+J`、`N`、`1-6`、`Esc`
- 右侧详情面板：任务详情、事件详情、状态动作、执行器分配

## 启动

```bash
pnpm install
pnpm dev
```

## 一期范围

- 仅 `Web SPA`
- 仅本地数据，不接真实后端
- 规则、信息源、执行器使用 mock 数据
- 交互闭环真实可用，便于二期接服务端

## 快捷键

- `Cmd/Ctrl + K`：打开命令面板
- `Cmd/Ctrl + J`：开关对话面板
- `N`：快速创建任务
- `1-6`：切换主页面
- `Esc`：关闭命令面板 / 详情焦点 / 对话

## 验证
