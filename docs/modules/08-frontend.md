# 前端 UI 产品设计文档

> 版本：v1 | 更新：2026-07-23

---

## 1. 模块定义

### 1.1 这是什么

前端 UI 是用户与系统交互的界面。

### 1.2 解决什么问题

- 需要直观展示信息
- 需要便捷的操作方式
- 需要实时的状态更新

### 1.3 核心价值

**一目了然，快速操作。** 信息清晰展示，操作简单直接。

---

## 2. 设计原则

### 2.1 视觉风格

- **明亮模式**：白色底色，不刺眼
- **参考 Linear**：简洁、高效
- **现代感**：圆角、阴影、渐变

### 2.2 交互原则

- **对话驱动**：所有操作可通过对话完成
- **面板展示**：信息一目了然
- **快捷键**：提高效率

---

## 3. 页面设计

### 3.1 仪表盘

**功能**：一眼看清今天的情况

**内容**：
- 今日接收事件数
- L3 必须你关注的事件数
- Agent 处理中的任务数
- AI 已完成的任务数
- AI 注意力隔离统计
- Agent 状态
- 事件趋势图

**价值**：2 秒了解今天的情况

### 3.2 事件流

**功能**：查看所有事件，按注意力级别分组

**内容**：
- L3 必须你（红色）
- L2 Agent 处理中（黄色）
- L1 AI 追踪中（蓝色）
- L0 已隔离（灰色）

**筛选**：
- 按级别筛选
- 按来源筛选
- 搜索

**价值**：快速找到需要关注的事件

### 3.3 任务

**功能**：查看和管理任务

**视图**：
- 看板视图：按状态分列
- 列表视图：按时间排列

**操作**：
- 创建任务
- 分配任务
- 更新状态
- 查看详情

**价值**：追踪任务进度

### 3.4 执行器

**功能**：管理 Agent 和人

**内容**：
- 执行器列表
- 状态监控（空闲/忙碌/离线）
- 能力配置
- 执行统计

**操作**：
- 添加执行器
- 启用/禁用
- 配置参数

**价值**：知道谁在干活

### 3.5 规则引擎

**功能**：管理分发规则

**内容**：
- 规则列表
- AI 建议规则
- 规则统计

**操作**：
- 通过对话创建规则
- 启用/禁用规则
- 编辑规则

**价值**：配置分发策略

### 3.6 信息源

**功能**：管理信息接入渠道

**内容**：
- 已接入的信息源
- 连接状态
- 消息统计

**操作**：
- 添加信息源
- 配置参数
- 启用/禁用

**价值**：管理信息渠道

---

## 4. 对话面板

### 4.1 侧面板模式

**位置**：右侧固定

**宽度**：默认 480px，可拖动调整（320px-800px）

**特点**：
- 不遮挡主内容
- 可以同时查看事件和对话
- 可以钉住，保持打开

### 4.2 弹窗模式

**位置**：居中

**特点**：
- 有遮罩背景
- 专注操作
- 适合创建任务

### 4.3 对话内容

**AI 主动推送**：
- 今日待办
- 异常提醒
- 处理结果

**用户操作**：
- 创建任务
- 分配任务
- 查询状态
- 修改设置

---

## 5. 快捷键

| 快捷键 | 说明 |
|--------|------|
| ⌘K | 命令面板 |
| ⌘J | 切换对话面板 |
| N | 新建事件/任务 |
| 1-6 | 切换页面 |
| Esc | 关闭弹窗 |

---

## 6. 响应式设计

### 6.1 桌面端（>1024px）

- 完整布局
- 侧面板固定
- 所有功能可用

### 6.2 平板端（768-1024px）

- 侧边栏可收起
- 侧面板变为弹窗
- 部分功能简化

### 6.3 移动端（<768px）

- 侧边栏隐藏
- 对话面板全屏
- 核心功能可用

---

## 7. 与其他模块的关系

| 模块 | 关系 |
|------|------|
| 任务管理 | 展示任务列表、任务详情 |
| 执行器 | 展示执行器状态 |
| 规则引擎 | 展示规则列表、规则编辑 |
| 对话引擎 | 对话面板展示 |
| 工作空间 | 工作空间切换器 |
