# 工作空间 产品设计文档

> 版本：v1 | 更新：2026-07-23

---

## 1. 模块定义

### 1.1 这是什么

工作空间用于隔离不同场景的事件和任务。

### 1.2 解决什么问题

- 工作和生活的事情混在一起
- 不同项目的事情混在一起
- 需要分场景管理

### 1.3 核心价值

**场景隔离，互不干扰。** 工作的事情在工作空间，生活的事情在生活空间。

---

## 2. 工作空间类型

| 类型 | 说明 | 适用场景 |
|------|------|----------|
| **个人空间** | 个人工作 | 日常工作任务 |
| **团队空间** | 团队协作 | 多人协作项目 |
| **学习空间** | 学习资料 | 读书笔记、学习计划 |
| **生活空间** | 生活事务 | 健康、财务、社交 |

---

## 3. 隔离范围

每个工作空间独立管理：

| 资源 | 是否隔离 |
|------|----------|
| 任务 | ✅ 隔离 |
| 规则 | ✅ 隔离 |
| 执行器配置 | ✅ 隔离 |
| 信息源配置 | ✅ 隔离 |
| 对话历史 | ✅ 隔离 |

---

## 4. 工作空间切换

### 4.1 切换方式

在侧边栏顶部的工作空间切换器中选择。

### 4.2 切换效果

- 显示该工作空间的任务
- 显示该工作空间的规则
- 显示该工作空间的配置

---

## 5. 预设工作空间

### 5.1 个人空间

- 默认工作空间
- 个人工作任务
- 3 个 Agent

### 5.2 团队空间

- 多人协作
- 共享任务和规则
- 5 人，8 个 Agent

### 5.3 学习空间

- 学习资料管理
- 读书笔记
- 学习计划

### 5.4 生活空间

- 生活事务
- 健康管理
- 财务记录
- 社交活动

---

## 6. 工作空间管理

### 6.1 创建工作空间

通过对话创建：
```
用户：创建一个学习空间
AI：✅ 学习空间已创建
```

### 6.2 删除工作空间

删除工作空间会删除其中的所有数据。

### 6.3 配置工作空间

- 设置默认优先级
- 设置默认注意力级别
- 配置通知方式

---

## 7. 团队协作（第二阶段）

### 7.1 成员管理

- 邀请成员
- 移除成员
- 设置角色

### 7.2 角色权限

| 角色 | 权限 |
|------|------|
| 管理员 | 所有权限 |
| 成员 | 查看、创建任务 |

### 7.3 共享

- 共享任务
- 共享规则
- 共享执行器配置

---

## 8. 与其他模块的关系

| 模块 | 关系 |
|------|------|
| 任务管理 | 任务属于某个工作空间 |
| 规则引擎 | 规则属于某个工作空间 |
| 执行器 | 执行器配置属于某个工作空间 |
| 插件系统 | 插件配置属于某个工作空间 |
