# 钉钉信息源 产品设计文档

> 版本：v1 | 更新：2026-07-23

---

## 1. 模块定义

### 1.1 这是什么

钉钉信息源是系统的第一个信息接入渠道，负责接收钉钉消息。

### 1.2 解决什么问题

- 钉钉消息淹没在群聊里
- 重要的消息被忽略
- 需要统一管理钉钉消息

### 1.3 核心价值

**钉钉消息不再漏掉。** AI 自动过滤，只把重要的推送给你。

---

## 2. 接入方式

### 2.1 Webhook

钉钉机器人通过 Webhook 推送消息到系统。

### 2.2 接入流程

1. 在钉钉开放平台创建应用
2. 添加机器人能力
3. 配置消息接收地址（系统的 Webhook 端点）
4. 系统开始接收钉钉消息

---

## 3. 消息类型支持

| 类型 | 说明 | 处理方式 |
|------|------|----------|
| 文本消息 | 普通文字消息 | 直接转换 |
| 图片消息 | 图片 | 保存图片信息 |
| 富文本消息 | 带格式的文本 | 解析富文本 |
| 文件消息 | 文件附件 | 保存文件信息 |
| 链接消息 | 链接 | 提取链接 |

---

## 4. 群消息处理

### 4.1 群消息来源

- 群聊消息
- @消息
- 系统通知

### 4.2 处理方式

| 消息类型 | 处理方式 |
|----------|----------|
| @机器人 | 优先处理 |
| @用户 | 根据规则处理 |
| 普通群消息 | 根据规则过滤 |

---

## 5. 消息过滤

### 5.1 过滤规则

系统根据规则自动过滤钉钉消息：

| 规则 | 处理 |
|------|------|
| 包含"紧急""告警" | L3 立即通知 |
| 来自特定群 | 根据群设置处理 |
| @机器人 | L3 立即通知 |
| 普通闲聊 | L0 自动归档 |

### 5.2 过滤效果

典型场景下：
- 100 条钉钉消息
- 80 条自动归档（L0）
- 15 条 AI 追踪（L1）
- 3 条 Agent 处理（L2）
- **2 条通知你（L3）**

## 6. 配置说明

### 6.1 必填配置

| 配置项 | 说明 |
|--------|------|
| App Key | 钉钉应用 AppKey |
| App Secret | 钉钉应用 AppSecret |
| Token | 消息加签 Token |
| AES Key | 消息加签 AES Key |

### 6.2 可选配置

| 配置项 | 说明 |
|--------|------|
| Corp ID | 企业 ID |
| Agent ID | 机器人 Agent ID（用于发送消息） |

---

## 7. 发送消息

### 7.1 功能

系统可以通过钉钉机器人发送消息给用户。

### 7.2 使用场景

- 任务通知
- 结果汇报
- 异常告警
