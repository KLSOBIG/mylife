# 对话引擎 产品设计文档

> 版本：v1 | 更新：2026-07-23

---

## 1. 模块定义

### 1.1 这是什么

对话引擎是用户与系统交互的主要方式。通过自然语言完成各种操作。

### 1.2 解决什么问题

- 传统工具需要点击多个按钮完成操作
- 记不住功能在哪里
- 需要一个更自然的交互方式
- 希望 AI 能理解意图并自动执行

### 1.3 核心价值

**一个对话框搞定一切。** 你说一句话，AI 理解意图，自动执行。

---

## 2. 对话类型

| 类型 | 说明 | 示例 |
|------|------|------|
| **创建任务** | 创建新的任务 | "创建一个紧急任务" |
| **查询信息** | 查询任务、状态 | "龙虾今天处理了多少任务" |
| **执行操作** | 分配、更新、删除 | "把这个任务分配给Harness" |
| **修改设置** | 系统配置 | "把通知方式改成钉钉" |

---

## 3. 参数推断

### 3.1 概念

AI 从你的输入中自动提取任务参数，不需要你填表单。

### 3.2 推断示例

| 你的输入 | AI 推断 |
|----------|---------|
| "处理客户投诉" | 标题：处理客户投诉 |
| "紧急：服务器故障" | 标题：服务器故障，优先级：紧急 |
| "把周报分配给龙虾，周五截止" | 标题：周报，分配：龙虾，截止：周五 |

### 3.3 推断规则

| 参数 | 推断方式 |
|------|----------|
| 标题 | 从输入提取核心内容 |
| 优先级 | 关键词（"紧急"→紧急） |
| 分配人 | 名字匹配（"给龙虾"→龙虾） |
| 截止时间 | 时间词（"周五"→本周五） |

---

## 4. 追问机制

### 4.1 何时追问

- 必要参数缺失且无法推断
- 关键决策需要确认

### 4.2 何时不追问

- 可以用默认值
- 可以从上下文推断
- 非必要参数

### 4.3 追问示例

```
你：创建任务
AI：请描述一下这个任务？

你：处理客户投诉
AI：优先级是什么？紧急/高/中/低

你：紧急
AI：✅ 任务已创建：处理客户投诉（紧急）
```

### 4.4 不追问示例

```
你：把周报分配给龙虾，周五截止
AI：✅ 任务已创建：周报，分配给龙虾，周五截止
```

（AI 自动提取了所有参数，不需要追问）

## 5. 对话模式

### 5.1 侧面板模式

右侧固定面板，可以同时查看主内容。

**特点**：
- 默认宽度 480px
- 可拖动调整宽度（320px-800px）
- 不遮挡主内容

**适用场景**：需要同时查看事件列表或任务详情

### 5.2 弹窗模式

居中弹出的对话框。

**特点**：
- 居中显示
- 有遮罩背景
- 专注操作

**适用场景**：不需要看主内容，专注于创建任务

### 5.3 模式切换

两种模式可以随时切换。

## 6. 快捷指令

### 6.1 预设指令

| 指令 | 说明 |
|------|------|
| /task | 创建任务 |
| /query | 查询 |
| /assign | 分配 |
| /help | 帮助 |

### 6.2 使用方式

在对话框输入 `/` 开头的指令，快速执行操作。

## 7. 对话历史

### 7.1 概念

系统记录所有对话历史，方便回溯。

### 7.2 功能

- 查看历史对话
- 搜索对话内容
- 清空历史
