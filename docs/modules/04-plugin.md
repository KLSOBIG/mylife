# 插件系统 产品设计文档

> 版本：v1 | 更新：2026-07-23

---

## 1. 模块定义

### 1.1 这是什么

插件系统是系统的扩展机制，通过标准接口接入各种能力。

### 1.2 解决什么问题

- 需要对接各种外部系统（钉钉、飞书、邮件等）
- 需要接入各种执行器（龙虾、Harness、Codex 等）
- 不同系统的接入方式不同（API、CLI、Webhook 等）
- 需要统一的扩展机制

### 1.3 核心价值

**标准化接入，即插即用。** 所有外部能力通过统一接口接入，系统只负责驱动。

---

## 2. 插件类型

| 类型 | 说明 | 示例 |
|------|------|------|
| **信息源** | 接收外部事件 | 钉钉、邮件、RSS |
| **执行器** | 处理任务 | 龙虾、Harness、Codex |
| **规则** | 定义分发策略 | 关键词规则、时间规则 |

---

## 3. 接入方式

| 方式 | 说明 | 适用场景 |
|------|------|----------|
| **API** | 调用远程接口 | GPT-4、在线服务 |
| **CLI** | 调用本地命令 | OpenCode、本地工具 |
| **SDK** | 直接调用代码库 | Go 库、Python 库 |
| **Webhook** | 接收推送 | 钉钉、飞书消息 |
| **轮询** | 定时拉取 | RSS、定时任务 |
| **流式** | 长连接 | 实时消息 |

---

## 4. 信息源插件

### 4.1 职责

接收外部信息，转换为系统事件。

### 4.2 接入流程

```
外部系统 → 信息源插件 → 系统事件 → 任务
```

### 4.3 预设信息源

| 名称 | 接入方式 | 说明 |
|------|----------|------|
| 钉钉 | Webhook | 接收钉钉群消息 |
| 邮件 | API | 接收邮件 |
| RSS | 轮询 | 定时拉取资讯 |

### 4.4 扩展信息源

| 名称 | 接入方式 | 说明 |
|------|----------|------|
| 飞书 | Webhook | 接收飞书消息 |
| 企微 | Webhook | 接收企业微信消息 |
| 爬虫 | 轮询 | 定时抓取网页 |

---

## 5. 执行器插件

### 5.1 职责

接收任务，执行并返回结果。

### 5.2 接入流程

```
任务 → 执行器插件 → 执行 → 结果
```

### 5.3 预设执行器

| 名称 | 接入方式 | 说明 |
|------|----------|------|
| 龙虾 | SDK | 信息处理 |
| Harness | CLI | 代码处理 |
| Codex | CLI | 架构设计 |
| OpenCode | CLI | 通用代码执行 |

### 5.4 扩展执行器

| 名称 | 接入方式 | 说明 |
|------|----------|------|
| GPT-4 | API | 大语言模型 |
| Claude | API | 大语言模型 |
| 自定义脚本 | CLI | 用户自定义 |

---

## 6. 规则插件

### 6.1 职责

定义分发策略，决定事件如何处理。

### 6.2 预设规则

| 名称 | 说明 |
|------|------|
| 关键词规则 | 按关键词匹配 |
| 时间规则 | 按时间匹配 |
| 来源规则 | 按来源匹配 |

---

## 7. 插件管理

### 7.1 添加插件

通过对话添加：
```
用户：接入飞书机器人
AI：请提供飞书应用的 App ID 和 App Secret
用户：xxx
AI：✅ 飞书已接入，开始接收消息
```

### 7.2 启用/禁用

每个插件可以独立启用或禁用。

### 7.3 健康检查

系统定期检查插件状态，异常时通知。

### 7.4 配置管理

每个插件有自己的配置项，通过界面或对话配置。

## 8. 插件配置

### 8.1 信息源配置示例

**钉钉**
```
App Key: xxx
App Secret: xxx
Token: xxx
AES Key: xxx
```

**RSS**
```
订阅源1: https://example.com/feed.xml
订阅源2: https://example2.com/feed.xml
轮询间隔: 30分钟
```

### 8.2 执行器配置示例

**OpenCode**
```
命令: opencode
参数: run
超时: 5分钟
```

**GPT-4**
```
API 端点: https://api.openai.com/v1/chat/completions
API Key: xxx
模型: gpt-4
```

## 9. AI 生成插件

### 9.1 概念

AI 可以根据用户描述，自动生成插件代码。

### 9.2 流程

```
用户：接入飞书机器人
AI：分析需求...
AI：生成插件代码...
AI：✅ 插件已生成，请配置 App ID 和 Secret
```

### 9.3 模板系统

系统提供插件模板，AI 基于模板生成：
- 信息源模板（API/Webhook/轮询）
- 执行器模板（API/CLI/SDK）
- 规则模板

## 10. 与其他模块的关系

| 模块 | 关系 |
|------|------|
| 任务管理 | 插件产生任务、处理任务 |
| 执行器 | 执行器以插件形式接入 |
| 规则引擎 | 规则以插件形式扩展 |
| 对话引擎 | 通过对话管理插件 |
